These are operational/discovery measurements, not reference-set recall or an official score. No third-party page bytes, keys or model responses are included.

`recalculate.py` repeats envelope counting from the repository root. It writes its result alongside the script, and hashes any local Markdown/archive files in that folder. Original downloaded materials remain in ignored `out/research-20261018`; therefore its material list will be empty in an otherwise clean clone. Use the checked-in JSON for hashes recorded during research.
